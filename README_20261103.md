# 신한투자증권 앱 자동매매 (안드로이드 폰 단독 구동)

## 동작 구조
- 신호앱 알림 수신 (Termux:API `termux-notification-list`)
  → 텍스트 파싱 (`삼성전자 매수 10주`)
  → 리스크 검사 (화이트리스트·수량·거래시간·중복·일일한도·킬스위치)
  → ADB(폰 자기 자신, 무선 디버깅)로 신한앱 화면 조작
  → 스크린샷 저장 + 텔레그램/로그 알림
- 의존성: Python 표준 라이브러리만 사용

## 0. 먼저 확인할 것 (실패 시 이 방식 불가)
- 신한앱이 **개발자 옵션 / 무선 디버깅 ON** 상태에서 정상 실행되는지
- 막히면 이 방식은 사용할 수 없음 (앱 보안 솔루션이 차단)

## 1. 설치 (Termux — F-Droid 버전, Play스토어 버전 X)
- F-Droid에서 **Termux**, **Termux:API** 설치
- Termux에서:
  - `git clone <저장소> && cd sinhanmacro`
  - `bash setup_termux.sh`

## 2. ADB 자기 연결 (Android 11+)
- 방법 A (포트 고정, 재부팅 전까지 유지) — PC 1회 필요
  - PC에서 USB 연결 후 `adb tcpip 5555`
  - Termux: `python -m sinhanmacro connect` (config `adb.serial` = `localhost:5555`)
- 방법 B (PC 없음, 무선 디버깅 사용)
  - 개발자 옵션 → 무선 디버깅 → "페어링 코드로 기기 페어링"
  - Termux: `python -m sinhanmacro pair localhost:<페어링포트> <코드>`
  - `config.json` 의 `adb.serial` 을 `localhost:<무선디버깅 포트>` 로 설정 후 `connect`
  - 무선 디버깅을 껐다 켜면 포트가 바뀜 → serial 갱신 필요
- 화면 유지: 개발자 옵션 "켜짐 상태 유지"(충전 중), 화면잠금 없음 권장

## 3. 신호 수신 권한
- 설정 → 알림 접근 허용 → **Termux:API** 허용
- 신호앱 패키지명 확인 후 `signal.source_packages` 에 입력

## 4. config.json 설정
- `app.package`: `python -m sinhanmacro find-package 신한` 으로 확인
- `symbols`: 거래 허용 종목 (코드 6자리, 기본/최대 수량) — 목록 외 종목은 무조건 무시
- `order.price_mode`: `market`(시장가) / `limit_from_signal`(신호의 가격으로 지정가)
- `dry_run`: **true 로 시작** (최종 제출 버튼 직전에 멈추고 화면 캡처만 저장)

## 5. flows 작성 (가장 중요 — 앱 화면에 맞춰야 함)
- 화면을 앱에서 직접 열어 둔 상태에서 `python -m sinhanmacro dump`
  → 요소별 `text / id / desc / center` 출력 + `shots/ui_dump_YYYYMMDD_HHMMSS.xml` 저장
- 출력 값으로 `flows.buy.steps` / `flows.sell.steps` 의 셀렉터 작성
  - 셀렉터 키: `text`, `text_contains`, `text_regex`, `id`, `id_contains`, `desc`, `desc_contains`, `class`, `clickable`, `index`
  - 템플릿 변수: `{code} {name} {qty} {price} {side}`
  - 노드가 안 잡히는 화면(WebView 등)은 `{"do":"tap_xy","xy":[x,y]}` 좌표 사용
  - 주문 제출 버튼 step 에 반드시 `"final": true`
  - `flows.<방향>.success`: 접수 완료 화면의 문구 (없으면 `unconfirmed` 로 알림)
- step 종류 상세: `sinhanmacro/executor.py` 상단 주석

## 6. 테스트 순서
1. `python -m sinhanmacro parse "삼성전자 매수 10주"` — 신호 파싱
2. `python -m sinhanmacro inject "삼성전자 매수 1주" --no-exec` — 리스크 검사까지
3. 신한앱 **수동 로그인** 후 `python -m sinhanmacro inject "삼성전자 매수 1주"` (dry_run=true)
   → `shots/before_confirm_*.png` 로 입력값 확인
4. 장중 소액(1주) `dry_run=false` 로 실전 테스트
5. `python -m sinhanmacro run` — 상시 감시 (Termux 에서 `termux-wake-lock` 유지)

## 안전장치
- 화이트리스트 외 종목 / 매수·매도 모호 / 우선주 오인 → 무시
- 종목별 `max_qty` 초과 거부, 일일 주문 `max_orders_per_day`, 동일 주문 `dedupe_minutes` 내 재주문 차단
- 거래시간(평일 09:00~15:20 기본) 외 차단 — **공휴일은 처리 안 함**
- 킬스위치: `python -m sinhanmacro stop` / `resume`
- 시작 시 이미 떠 있던 알림은 무시 (과거 신호 재실행 방지)
- 제출 후 오류/미확인 시에도 주문 기록 → 중복 주문 방지

## 한계 / 주의
- **로그인은 자동화하지 않음**: 보안키패드(랜덤 배열)·인증서·생체인증은 수동. 로그아웃 상태면 주문 중단 + 알림
- 주문 비밀번호를 매번 요구하는 설정이면 자동화 불가 → 앱에서 생략 설정 가능한지 확인
- 지정가는 호가 단위에 맞아야 함 (신호 쪽에서 맞춰서 전달)
- 앱 업데이트로 화면이 바뀌면 flows 재작성 필요
- 증권사 약관 위반·계정 제재 가능성, 모든 매매 손익은 본인 책임
- 이 코드는 실제 신한앱/실기기에서 검증되지 않음 (단위 테스트는 가상 화면 기준) → 반드시 dry_run 으로 단계별 확인
